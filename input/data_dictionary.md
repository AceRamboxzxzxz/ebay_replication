# Data Dictionary: PaidSearch.csv

| Variable | Description |
|----------|-------------|
| `date` | Date of the observation (daily frequency, April–July 2012) |
| `dma` | Designated Market Area identifier |
| `treatment_period` | 0 = pre-treatment; 1 = post-treatment |
| `search_stays_on` | 0 = treatment group; 1 = control group |
| `revenue` | eBay revenue for that DMA on that date (USD) |

## Source
Blake, Nosko & Tadelis (2014), Econometrica.
